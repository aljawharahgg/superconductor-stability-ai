# Superconductor Stability Monitoring and Critical Temperature Prediction Using Machine Learning

**Senior Graduation Project — Imam Abdulrahman Bin Faisal University**
**College of Computer Science and Information Technology — Department of Computer Engineering | 2026–2027**

## About

This project aims to develop an AI-powered system for **predicting the critical temperature (Tc) of superconducting materials** and **monitoring their stability using real-time sensor data**.

The system combines **machine learning** with an **ESP32-based IoT monitoring system** to analyze superconducting material properties, collect sensor measurements, and visualize predictions and real-time data through a monitoring dashboard.

## Technologies

`Python` • `Machine Learning` • `ESP32` • `IoT` • `Data Analysis` • `Data Visualization`
